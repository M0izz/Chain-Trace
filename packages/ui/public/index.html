01 / THE FOUNDATIONAL FLAW

Existence is not execution proof.

A source transaction and a destination transaction existing on respective blockchains does not, by itself, establish a valid cross-chain causal relationship.

NAIVE ASSUMPTION

Superficial Hash Matching

Conventional indexers see a transaction on Chain A and a transfer on Chain B. If amounts loosely align, they mark the transfer "complete". They fail to prove:

  • Did the emitting contract actually execute with success status (0x1)?
  • Has the source block reached mathematical finality, or is it subject to reorg?
  • Did the destination delivery emit the exact cryptographic GUID dispatched?
CHAINTRACE RIGOR

Evidence-Backed Causality

Every status must cite verifiable evidence records evaluated under explicit policy versions. If a link cannot be independently validated, it is labeled truthfully:

  • Direct JSON-RPC confirmation of execution status and event log indexes.
  • Exact confirmation depth calculation against profiled finality thresholds.
  • Cryptographic message GUID extraction and pairwise topic authentication.

03 / DEPENDENCY INTELLIGENCE

Revalidation without erasure.

When a blockchain reorganizes or evidence changes, naive systems either delete records or falsely invalidate independent destination facts. ChainTrace propagates revalidation strictly across affected descendants.

⚡

1. Directed Acyclic Graph

Claims and evidence form an acyclic dependency graph. Invariant checkers enforce cycle rejection at write time so causality is strictly ordered.

🎯

2. Isolated Descendant Invalidation

If block #5,420,052 mutates its block hash, only the SOURCE_FINALIZED and downstream MESSAGE_MATCHED claims transition to REVALIDATION_REQUIRED.

🛡️

3. Destination Fact Preservation

The destination transaction on Polygon Amoy is an immutable historical observation. It is never rewritten or labeled invalid simply because its causal origin is uncertain.

        05 / TRUST BOUNDARIES

        Explicit assumptions. No hidden trust.

        Scientific verification requires disclosing what is assumed versus what is independently proved. ChainTrace never claims trustless consensus without qualification.

        ASSUMPTION 01

        RPC Provider Honesty

        Verification results trust the observed Ethereum Sepolia and Polygon Amoy RPC nodes for raw receipt fields and logs. Content hashes detect post-facto modification of stored records, not provider fraud at ingestion.

        ASSUMPTION 02

        12-Block Finality Guard

        Sepolia transactions with 12 or more confirmations are modeled as non-reorganizable. If a deeper chain reorganization occurs, the system records it as an anomalous state transition via the audit trail.

        ASSUMPTION 03

        LayerZero DVN Quorum

        The system verifies that the LayerZero EndpointV2 contract on Polygon Amoy emitted PacketDelivered with matching GUID. It does not re-execute internal DVN threshold multisig off-chain.

        ASSUMPTION 04

        Append-Only Immutability

        State transitions are protected by SHA-256 hash chaining (prev_hash ➔ record_hash). Application routes cannot update or delete historical audit rows.
